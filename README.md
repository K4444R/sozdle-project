# Sozdle Project

## Description
Sozdle is a fun and engaging word puzzle game inspired by the popular game Wordle. It aims to provide a similar gameplay experience with some unique twists and features.

---

## Features
- Interactive word puzzle gameplay.
- Color-coded feedback for correct and incorrect guesses.
- Backend implemented in **Rust**.
- Frontend built with **JavaScript**, **CSS**, and **HTML**.
- Clean and modular code organization using MVC architecture.

---

## Getting Started
### Prerequisites
- **Rust** (version 1.70 or higher).
- **Node.js** (version 14 or higher).
- **npm** (version 6 or higher).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mmargullan/sozdle-project.git
   cd sozdle-project
   ```

2. Install backend dependencies:
   ```bash
   cargo build
   ```

3. Install frontend dependencies:
   ```bash
   cd front-end
   npm install
   cd ..
   ```

---

## Running the Application
### Backend
Run the Rust server:
```bash
cargo run
```

### Frontend
Navigate to the frontend directory and start the development server:
```bash
cd front-end
npm start
```
Open your browser and go to `http://localhost:5173` to see the game in action.
